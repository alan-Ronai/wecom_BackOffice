# L2 — API Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement every stage-1 library endpoint (documents, blocks, fields, scripts, notes, drafts, search, trash, preferences, SSE events), the audit helper, the nightly jobs, and the seed command that loads today's content, so the frontend (L4) and the pipeline (L5) have a real API to build on.

**Architecture:** Fastify modules under `apps/api/src/modules/<name>/` with `routes.ts` (zod-typed handlers) and `repo.ts` (plain SQL through `pg`). Documents are stored normalized (documents / phases / steps / step_actions / step_outcomes / step_branches / step_branch_options) and assembled into the shared `Document` schema on read; structure saves rewrite the rows in one transaction and recompute `step_field_refs`, `document_links` and `documents.search_text` with the shared detectors. Publishing freezes the assembled document into `document_versions`. Events go through Postgres `LISTEN/NOTIFY` so several API instances stay consistent and are streamed to browsers over SSE. Auth is L3's: routes declare `config.requires` and read `req.user`; tests inject a user through a fake-auth plugin.

**Tech Stack:** Node 22, Fastify 5, fastify-type-provider-zod 4, pg 8, pg-boss 10, zod 3, `@wecom/shared` (schemas, `fmt`, `wordDiff`, `stepText`, `detectFieldRefs`, `detectLinks`, `makeEvent`), vitest 2, @testcontainers/postgresql.

**Spec:** `docs/superpowers/specs/2026-09-13-kb-platform-stage1-foundation-design.md` (§2 data model, §4 API surface, §6 tests/seed) and `docs/superpowers/specs/2026-09-13-kb-platform-program-and-lanes.md` (§5 lane L2, §6 contracts 2–4, 7). Builds on `docs/superpowers/plans/2026-09-13-L0-contracts-and-scaffold.md` (Tasks 3–10, 13, 14).

## Global Constraints

- Node `>=22`, pnpm `>=9`, TypeScript `strict: true`.
- Every request/response uses the zod schemas exported by `@wecom/shared`; never re-declare a schema locally. Additive schema changes (new export) are allowed per ADR 0001; edits to existing schemas need an ADR.
- Route permission declaration exactly: `config: { requires: ['docs.publish'], scope: 'document' }` (scope optional). Permission strings only from `PERMISSIONS` in `@wecom/shared`.
- Event names only from `EVENTS` in `@wecom/shared`; payloads built with `makeEvent`.
- Error envelope `{ code, message, details?, requestId }`; pagination `{ items, total, page, pageSize }`; every write returns `{ auditId }` alongside its payload where the spec says so (publish, delete, restore).
- Column names exactly as in L0 Task 14 migrations (snake_case).
- Hebrew for user-facing messages, English for code and logs.
- Commit after every task, attribution lines from the session appended to every commit message.

## Decision: card-only topics

Library cards that have no written procedure (today's `KB.TOPICS` entries without `docId`) are stored as `documents` rows with `status = 'draft'`, zero phases, `topic_id` = legacy numeric id, `current_version = 0`. The list endpoint returns them as cards with `stepCount = 0`; the frontend renders them as placeholders ("כרטיס ללא מסמך"). Writing the procedure is an ordinary `PUT /documents/:id/structure` + publish. No separate table.

## Cross-lane reconciliation (authoritative — added after the eight plans were reviewed together)

These names win over anything else in this file. They are the L0-owned contract for runtime glue (ADR 0001).

- **Job queues**: import `QUEUES` from `apps/api/src/plugins/boss.ts` (owned by L1) and never spell queue names inline. Catalogue: `pipeline.process` (L5, concurrency 1), `sources.watch` (L5), `connector.run` (L6, one cron schedule per connector, job key = connector id), `connector.webhook` (L6), `identity.sync` (L3), `trash.purge` (L2), `search.reindex` (L2), `system.backup-check` (L1). The decorator is `app.boss: PgBoss | null`; there is no `plugins/jobs.ts`.
- **Audit**: low-level `audit(tx, { actorId, action, entityType, entityId, before, after, requestId, ip }): Promise<string>` lives in `apps/api/src/lib/audit.ts` (owned by L2; L3 creates it with this exact signature only if L2 has not landed). L3's auth plugin additionally decorates the convenience wrapper `app.audit(req, action, entityType, entityId, before, after)` which fills `actorId = req.user?.id ?? null`, `requestId = req.id`, `ip = req.ip` and runs on `app.db`. L6 uses the wrapper; L2/L5 use the low-level function inside their transactions.
- **Events**: `app.events: EventBus` from `apps/api/src/lib/events.ts` (L2) with `publish(tx, event)` where `event = makeEvent(name, payload)` from `@wecom/shared`. No lane creates `plugins/events.ts`.
- **Auth**: `apps/api/src/plugins/auth.ts` (L3) sets `req.user: AuthUser = { id, displayName, roles, permissions: Set<string>, categoryScopes: string[] | null, sessionId }` (`displayName` is an additive field L3 includes) and enforces route `config: { requires: Permission[], scope?: 'document' }`. No lane adds a `requires()` preHandler or `plugins/authz.ts`; until L3 lands, tests use the `x-test-user` header plugin from L2 (`apps/api/test/helpers/fakeAuth.ts`) or `buildApp({ testUser })` — both must set the same `AuthUser` shape.
- **Module registration**: every `/api/v1` module registers inside the single `v1` callback in `apps/api/src/app.ts` via `registerModules(v1)` from `apps/api/src/modules/index.ts` (L2); other lanes add one line there.
- **For this lane**: replace inline `'trash.purge'` / `'search.reindex'` with `QUEUES.trashPurge` / `QUEUES.searchReindex`; export `registerModules(v1)` and keep `app.events`/`audit()` exactly as above since three other lanes depend on them.

```ts
import type { ReqUser } from '../../src/lib/user.js';
/** Test-only: `x-test-user: {"id":"…","permissions":["docs.read"],"categoryScopes":null}` */
export default fp(async (app) => {
  app.addHook('onRequest', async (req) => {
    const raw = req.headers['x-test-user'];
    if (typeof raw !== 'string') return;
    const u = JSON.parse(raw) as { id: string; permissions: string[]; categoryScopes: string[] | null };
    req.user = { id: u.id, permissions: new Set(u.permissions), categoryScopes: u.categoryScopes ?? null } satisfies ReqUser;

  // minimal enforcement mirror of L3's middleware so route `requires` is exercised in tests

  });
```

`src/lib/sql.ts`:
```ts
import type pg from 'pg';
export type Tx = pg.PoolClient;
export async function withTransaction<T>(pool: pg.Pool, fn: (tx: Tx) => Promise<T>): Promise<T> {
  const client = await pool.connect();
  try { await client.query('begin'); const r = await fn(client); await client.query('commit'); return r; }
  catch (e) { await client.query('rollback'); throw e; }
  finally { client.release(); }
}
```

```ts
export interface AuditInput { actorId: string | null; action: string; entityType: string; entityId: string | null; before: unknown; after: unknown; requestId: string | null; ip: string | null }
export async function audit(tx: Tx, a: AuditInput): Promise<string> {
  const r = await tx.query('insert into audit_log(actor_id, action, entity_type, entity_id, before, after, request_id, ip) values ($1,$2,$3,$4,$5,$6,$7,$8) returning id',
```

`src/lib/events.ts`:
```ts
import { EventEmitter } from 'node:events';
import pg from 'pg';
import { EventSchema, type Event } from '@wecom/shared';
import type { Tx } from './sql.js';
const CHANNEL = 'kb_events';
export class EventBus {
  private emitter = new EventEmitter();
  private client: pg.Client | null = null;
  async start(databaseUrl: string) {
    this.client = new pg.Client({ connectionString: databaseUrl });
    await this.client.connect();
    this.client.on('notification', (n) => { if (n.channel !== CHANNEL || !n.payload) return; const parsed = EventSchema.safeParse(JSON.parse(n.payload)); if (parsed.success) this.emitter.emit('event', parsed.data); });
    this.client.on('error', () => { /* reconnect handled by restart in jobs; log at caller */ });
    await this.client.query(`listen ${CHANNEL}`);
  }
  async stop() { await this.client?.end(); this.client = null; this.emitter.removeAllListeners(); }
  /** Publish inside a transaction: NOTIFY fires only on commit. */
  async publish(tx: Tx, event: Event) { await tx.query('select pg_notify($1, $2)', [CHANNEL, JSON.stringify(event)]); }
  subscribe(fn: (e: Event) => void): () => void { this.emitter.on('event', fn); return () => this.emitter.off('event', fn); }
}
```

```ts
import { escapeHtml, stripFmt, wordDiff, type Block, type Document, type Step } from '@wecom/shared';
export interface DiffSide { key: string; num: string; titleHtml: string; lines: string[] }
export interface DiffRow { kind: 'same' | 'changed' | 'added' | 'removed'; oldStep: DiffSide | null; newStep: DiffSide | null; blame?: { version: number; author: string } }
export const stepLines = (s: Step, blocks: Map<string, Block>): string[] => {
  const b = s.blockId ? blocks.get(s.blockId) : undefined; const lines: string[] = [];
  if (s.blockId) lines.push('⧉ בלוק משותף: ' + (b?.title ?? s.blockId));
  for (const a of b?.actions ?? s.actions) lines.push('› ' + stripFmt(a.text));
  if (s.script ?? b?.script) lines.push('“ ' + stripFmt(s.script ?? b?.script));
  if (s.branch) { lines.push('? ' + s.branch.q); for (const o of s.branch.options) lines.push('• ' + o.label + ': ' + stripFmt(o.text)); }
  for (const o of s.outcomes) lines.push(stripFmt(o.text));
  return lines;
};
const sig = (s: Step, blocks: Map<string, Block>) => stripFmt(s.title) + '\n' + stepLines(s, blocks).join('\n');
export function diffDocuments(oldDoc: Document, newDoc: Document, blocks: Map<string, Block>): DiffRow[] {
  const O = oldDoc.phases.flatMap((p) => p.steps), N = newDoc.phases.flatMap((p) => p.steps);
  const oldIdx = new Map(O.map((s, i) => [s.key, i])); const rows: DiffRow[] = []; let cursor = 0;
  const side = (s: Step, lines: string[], titleHtml: string): DiffSide => ({ key: s.key, num: s.num, titleHtml, lines });
  const pair = (o: Step, n: Step): DiffRow => {
    const same = sig(o, blocks) === sig(n, blocks); const ol = stepLines(o, blocks), nl = stepLines(n, blocks); const la: string[] = [], lb: string[] = [];
    for (let i = 0; i < Math.max(ol.length, nl.length); i++) { const d = wordDiff(ol[i] ?? '', nl[i] ?? ''); if (ol[i] != null) la.push(d.a); if (nl[i] != null) lb.push(d.b); }
    const t = wordDiff(stripFmt(o.title), stripFmt(n.title));
    return { kind: same ? 'same' : 'changed', oldStep: side(o, la, same ? escapeHtml(stripFmt(o.title)) : t.a), newStep: side(n, lb, same ? escapeHtml(stripFmt(n.title)) : t.b) };
  };
  const removed = (o: Step): DiffRow => ({ kind: 'removed', oldStep: side(o, stepLines(o, blocks).map(escapeHtml), escapeHtml(stripFmt(o.title))), newStep: null });
  for (const n of N) {
    const oi = oldIdx.get(n.key);
    if (oi !== undefined) { while (cursor < oi) { const o = O[cursor++]; if (!N.some((x) => x.key === o.key)) rows.push(removed(o)); } cursor = oi + 1; rows.push(pair(O[oi], n)); }
    else rows.push({ kind: 'added', oldStep: null, newStep: side(n, stepLines(n, blocks).map(escapeHtml), escapeHtml(stripFmt(n.title))) });
  }
  while (cursor < O.length) { const o = O[cursor++]; if (!N.some((x) => x.key === o.key)) rows.push(removed(o)); }
  return rows;
}
```
